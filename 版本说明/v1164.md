# v1164 版本说明

> 每个版本一份。机器生成的部分在「自动生成」两行之间；其余由做这一版的人写，写给不熟悉电脑的老师看。

## 给老师看：这一版改了什么

**天梯排位和房间对战的底层全部推倒重做，现在应该能在真手机上用了。**

- **为什么以前一直不行：** 客人进房、准备、抢答、交卷，每一步都要去改「房主建的那条房间记录」，
  而腾讯云数据库只许「谁建的谁改」。所以客人每一步都悄悄失败；报错又被吞掉，只剩一句「连不上网络」。
  v1157–v1163 修过 22 个对战问题，都没碰到这个根。
- **现在：** 每个人只写自己建的记录（房主建房间、客人建座位、谁抢到谁建那一回合的结果）。
  **不需要你在腾讯云后台改任何设置。**
- **出错时说真话：** 断网、太慢、登录过期、云端设置不对、房已经没了、被别人抢先……分开说；
  「技术信息」那一行保留原话，方便截图给我。
- **孩子的数据更安全：**
  - 房间记录里不再有手机号；
  - 好友页一个能偷登录凭证的漏洞堵上了；
  - 修好 3 种会让云端的词被手机上的旧数据盖掉的情况（例如云端 20 个词被盖成 4 个）；
  - 对战中整页不会再被突然刷新。
- **更公平、更结实：** 用电脑模拟了 6904 局（网慢、断网、手机时间不准、切到微信、有人捣乱），
  出问题的局从 134 降到 4，剩下的 4 局是一个已知限制（见「已知问题」）。

## 详细改动

1. **联机地基重做**（`hansen_pk_room_v1065.js`、`hansen_pk_room_ui_v1065.js`）
   - 房间、座位（房间号 + `_s` + 轮次）、每回合结果（房间号 + `_w` + 回合号）三种记录，每人只写自己建的；
     抢座位、抢答靠「同一个编号只能建成一个」，建完一定回读确认。
   - 房主确认座位后还要等客人回话才开打；客人走了，房主撤回、换下一个轮次。
   - 判断对方掉线只看「对方心跳多久没变」，用本机时钟计时，不受两台手机时间差影响。
   - 记录带 `proto: 2`，旧版本留下的房间不显示。
2. **错误分类**：所有云端调用都检查 `code`，分成 9 种原因，界面按原因说话，原话保留在「技术信息」。
3. **登录与会话**（`hansen_auth_v1004.js`）
   - 用户 ID 不再只信手机本地缓存；「用户名 + 密码注册」现在真的在云端建账号。
   - 备份不再把 SDK 自己的登录缓存当成玩家数据导出、恢复。
4. **数据安全**（`hansen_auth_v1004.js`、`hansen_backup_v944.js`）
   - 登录后的对账不再和自动上传抢跑；对账失败后，所有页框共用一个「下次再试」的时间。
   - 恢复存档到刷新之间的 1.2 秒「冻结写入」：30 秒自动失效，不会卡死。
   - 查「忙不忙」查整个标签页：对战中、等人、加入中、建房中、天梯页开着，都不在后台恢复、刷新；跳过的下次再对账。
5. **隐私和安全**
   - 房间记录不存手机号、用户名，名字从玩家资料取。
   - 修好好友页的存储型 XSS（别人能读走孩子的手机号和登录凭证）。
6. **云端额度**：对战、匹配时读数据库的次数大幅减少；好友在线心跳不再在 3 个页框里同时跑。
7. **压力测试找出的 12 类问题（R1–R12）全部修好**，例如：

   详见 `攻坚笔记/v1164/联机压力测试_fuzz.md`。

## 已知问题和没验证的

- **两部手机的时间差 30 分钟以上**，天梯里互相找不到（要用服务器时间才能根治，这里没法在真服务器上验证，没做）。
- **交卷前后断网超过 1 分钟**：断网时拼对的那个词，交卷时少算它的分（压力测试 sweep 场景剩下的 3 局就是这个）。
- **有人改了程序故意捣乱**（占座、冒充）只能挡住一部分；网特别慢时，两部手机在同一两秒里各自下结论，还有很小的可能对不上。
  彻底解决要靠云函数做裁判，需要你在后台部署，这次没做。
- **房主暂停时，正在进来的客人可能被告知「这间房刚被别人占了」**（第三轮发现的小问题，改了反而可能让已经进来的客人收不到「被请出」的信号，所以没改）。
- **真服务器上没验证过的：**
  - 「同一个编号重复新建」时，真服务器怎么回应；
  - 服务器给每条记录盖的创建者标记（`_openid`）在网页登录下是否和模拟的一样；
  - 读到自己刚写的数据要多久。

  这台工作机连不上腾讯云，这些都是读 SDK 源码 + 本地模拟云端推断的。
- **首页外壳没有备份模块**（和以前一样，不是这次改出来的）。
- GitHub 上跑的是无头浏览器，不是微信里的浏览器；声音、字号放大、低端机耗电，要在真手机上看。
