## 2. 关键决定（没人可问，全部自己定，理由都写在 DESIGN.md）

1. **一个英文拼写 = 一个复习项。** 952 个槽位合成 936 个词；16 个词在两个岛（orange、fish、teacher…），只复习一次，两个岛同时记上。
   同形多义（orange 橙色/橙子）也合并：复习考的是「认得、拼得出这个英文」。
2. **间隔保留 1/2/4/7/15**（不迁移旧计划、和岛里同一套）。复习里**答错降一盒（一天只降一次）、今天还算到期**；
   今天答错过又答对 =「重新记住」：明天见、不升盒、不给钱。
   （第一版是「答错明天见」，测试时发现「故意全答错」就能让今天清零领 +20，改了。）
3. **掌握星只看真实证据**：不同日子答对过几次（结晶星、计划盒子、复习记录取最大，不相加）+ 自己拼对过几次（宠物爪、复习里无提示拼对）。
   「我认识了」不算星。还在错题本 / 计划里的词先封顶（错 1–2 次 ≤2 星、≥3 次 ≤1 星；计划里 ≤3 或 4 星）。
4. **出题自适应**：0–1 星听音 / 看图，2 星三种都有，3 星以上拼写为主；同一题型不连出 3 道；拼写不超过一半；
   每轮最多 12 个到期词 + 3 个巡检词（约 5 分钟）；同一天题目固定（刷新换不了简单题）；看图题的图上印着英文就不出；
   听音题每个选项只写一个意思（不然 orange 是唯一带斜杠的选项）。
5. **奖励不新开钱包、和岛里共用收据**（`rvrw:<日>:<槽>:c1..c3` +2、`:grad` +15、`:todaydone` +20、巡检 `:patrol` +3 由 v963 自己发）。
   复习里不发 +1 答题金、不推进结晶、不推进宠物爪（各有自己的防刷和钻石/宠物奖励）。练一练、再考一次、重新记住都不给钱。
6. **写账本只走现有接口**：先并入页面内存 → `read()` → 改这个词的槽位（计划带递增 `updatedAt`；清零 / 毕业立墓碑，和 `absorbAnswer` / `setSrs` 同语义）
   → `write(副本, true)` → 把这个岛的各份旧存档 `syncState` 成账本的样子 → 同源页面框 `syncCurrent()` → 写一个 `_bump` 键让别的标签页同步。
   自己只新增 `hansen_review2_v1166`（+`_bak`、`_bump`）。读不到账本就不出题、不写。
7. **时间**：一天按手机本地 0 点；日期加减按公历日期算；往回拨 ≤2 天按见过的最晚日期（不倒退、不能重领），拨回更多认为以前错了；
   计划里比今天晚 30 天以上的到期日当今天到期。
8. **家长面板没有家长锁**（只读、没有敏感信息，加锁只会挡住老师）；报告图本机 canvas 画，不联网，不写真名 / 手机号 / ID。

## 3. 发现的问题

### 3.1 现有账本：错题从 2 减到 1，会被 `_bak` 冲回 2（**建议单独修**）
`hansen_canonical_progress.js` 每次读都把主档和上一代 `_bak` 合并，错题数「取大」，只有「有墓碑」才不取大；
而墓碑只在错题**清零**时才写。所以错题 2→1（没清零）写进主档后，下一次读就被 `_bak` 里的 2 冲回去。
岛里的 `absorbAnswer` 就中招：在岛里答对一次 2→1，离开再回来又是 2（复习计划 v1165 那一套不受影响，只是错题数）。
**复现**（node，真账本模块）：
```js
// 装好 hansen_canonical_progress.js，S={learned:[],wrongs:{},mc:{},srs:{},stats:{}}，__hsnSaveKey='wordIslandFood'
S.wrongs[3]=2; HansenCanonical.absorbAnswer(3);   // 账本 {3:2}
S.wrongs[3]=1; HansenCanonical.absorbAnswer(3);   // 再读账本：还是 {3:2}
```
复习 2.0 用 `write(副本, true)`（exactBackup，主档和 `_bak` 写成同一份）绕开了，测试里专门验了「2→1 重新读还是 1」。
修法建议见 `INTEGRATION.md` §6-1（错题变小也写墓碑），按「不改现有文件」的要求本轮没动。

### 3.2 老存档的宠物爪偏高（只记录，不改）
v942 的一次性迁移（`hansen_pet_showcase.js` ≈:270）把当时「我认识了」且没错过的词宠物爪直接记成 3。
这些老词在掌握星里「自己拼过」的证据偏高，最多让老词早一点到 3 星（还要不同日子答对的天数够）。改它就是迁移别人的数据，不做。

### 3.3 测试时测出、已在本轮修掉的（都是新代码自己的）
- 答错「明天见」能刷 +20 → 改成今天还到期（§2-2）。
- 家长页长内容时条形图被压成 0 高 → `flex-shrink:0`。
- 亮色主题小字对比度 4.43 → 全部用 `--pal-ink-2`，最低 5.17。
- 没词可练时「练一练」按钮原地打转 → 只在有词可练时出现。
- 听音题选项斜杠送答案 → 每个选项一个意思。
- 结果页金币没算巡检 +3 → 如实显示（和钱包涨的一样）。
- 报告图「1 天 / 连续复习」两行字压在一起 → 重排。
