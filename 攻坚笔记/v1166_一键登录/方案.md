# v1166 一键登录（「一点就进」）方案

> 2026-11-04 老师提的：在微信里用别的小程序，右下角头像写「未登录」，点一下就登录好了，不用手机号验证码。希望我们也这样。

## 为什么不能和那个小程序一模一样

- 那个是**真正的微信小程序**（右上角有「··· ◎」胶囊）：微信自动告诉它「你是谁」，还能用「微信手机号快速验证」。
- 我们是**在微信里打开的网页**。网页要拿到微信身份，只能通过**已认证的微信服务号**（要学校 / 公司这类机构主体，个人申请不了，认证每年 300 元）。
- 老师 11-04 确认：**没有认证服务号** → 做「一点就进」。以后有了服务号，可以再加真正的「微信一键登录」（SDK 2.30 里有 genProviderRedirectUri / grantProviderToken / signInWithProvider，接腾讯云「身份源」）。

## 「一点就进」是什么

- 点一下 → 立刻建好一个云端账号（腾讯云匿名登录；`hansen_auth_v1004.js` 开头写着控制台已开通匿名登录，做的时候要再确认）。
  不要手机号、不要验证码；自动起一个名字，头像孩子自己选。进度照样存云端，天梯、房间、好友都能用。
- 和手机号账号唯一的不同：账号认的是「这部手机上的这个微信」。**换手机或清微信缓存之前，绑一次手机号**就不丢。
  孩子有了一些进度以后，温和地提醒一次（可以「以后再说」）。
- 现在的「升到 Lv.3 必须用手机号注册」改成这一下。
- 点天梯 / 拼写大PK / 好友时没登录：也是这一下，不再弹手机号表单。

  - 「招募中 → 点我加入」意思本来就通；5 个主题各自的胶囊配色都要跟着做；没登录的小头像按金色风格重画（示意图里是临时表情）。

## 做的时候必须验证（完美主义）

- 匿名账号在天梯、房间、好友、云存档（包括 `hansen_saves` 改成「读取和修改本人数据」以后）都能用 —— 真 SDK + 模拟云端测试。
- 匿名账号绑手机号以后，进度一点不丢；绑的手机号已经是别的账号时怎么办要说清楚。
- 清缓存会丢账号这件事，界面要说实话。
- 每一处都要有「改回去就红」的测试。
