## 三、做过的决定（都写了理由，都能推翻）

1. **全部加 `t2` 前缀**（`--t2-*`、`.t2-*`、`data-t2-*`）。样稿的 `--hi`/`--line` 在拼写蜂里已存在，`--font-body` 在首页/岛页已存在，`body[data-theme]` 被金币主题和拼写蜂占用。前缀 = 零冲突，也让 `grep` 能数迁移进度。
2. **门禁比样稿更严**：多查了星云叠在背景上的最坏情况、两种卡面上的图标、18 个玩法卡渐变端点、场景图取样、主题两两差异。第一次跑抓出 26 对不达标 + 1 组太像，**对样稿颜色做了最小调整**（都在 registry 里）：
   - 极光青 / 森野绿 / 金币·海洋蓝 / 金币·彩虹云朵：背景顶端 `bg_3` 调暗（顶部标题叠在星云上原来只有 3.45–4.2）；
   - 薄荷绿 / 冬日雪国 / 六一派对 / 晨曦：输入框边线 `line_strong` 稍加深（在抬高面板上原来 2.83–2.97）；
   - 所有亮色主题的经验条左端 `xp_1` #16A34A → #159C47（晨曦面板上原来 2.98）；
   - 冬日雪国天空更偏冰蓝（原来和云端白 ΔE 只有 9，看不出是两个主题）。
3. **买过的金币主题不是简单换成免费配色**：每个都声明亮/暗（修 TV-02 首页亮、岛内暗），同时保留自己的背景“身份色”，不然花金币买的东西就和免费的一模一样了。门禁要求可选主题两两 ΔE ≥ 10。
4. **显示优先级照搬现在的画面**：钻石场景 > 季节选择 > 非默认配色 > 已买的金币主题 > 深空蓝。没付钱的金币主题、没买的钻石主题不显示（与 `hansen_theme_lock` / 商店读法一致）。
5. **季节主题过了季节不强制撤掉**（孩子不喜欢东西“自己消失”）；孩子之后在老设置里换配色或金币主题，季节选择**自动失效**（记下了选的时候的配色）——老界面不用改也不会“换了没反应”。
6. **拼写蜂没选过的人改为跟随全局**（原来默认晴空亮色，TV-12）。这是行为变化，接入时需要老师真机看一眼。
7. **卡通字（398 KB）不放进首屏 CSS**，改由 fonts 模块在 DOMContentLoaded 注入：比现在的 window.load 早得多，又不和首屏抢流量；字体地址按脚本所在目录算（测试时发现按页面地址算会在子路径下 404，已修）。Baloo2 只有 18 KB，直接在 CSS 里声明。
8. **粒子上限按“同一时刻全局”算**，不是每次调用各 28 个——两个特效叠在一起也不超。样稿的结算页一共撒 48 个，2.0 配方改成 3×4 星点 + 16 片彩纸 = 28。
9. **做题中**：升级 / 进化 / 成就只记下来（v321 升级不挡做题）；宝箱 / 结算 / Boss 庆祝在做题中直接拒绝；答对的小庆祝允许（图层 `pointer-events:none`，测试证明特效播放时按钮照样点得到）。
10. **工具放 `攻坚笔记/theme2/tools/`**：`_*.mjs` 被 `.gitignore` 忽略提交不上去，根目录其他 `.mjs` 会被 `tcb hosting deploy` 传上线。
11. **新文件内容里不写版本号字面量**，测试按规律找文件（`/^hansen_fx_v\d{4}\.js$/`），批量升版不会把测试弄坏。

## 四、还有的风险 / 没做的

1. **还没接进游戏**（按任务要求只做新文件）。现在线上画面完全不变；效果要等 INTEGRATION 第 1–5 步。
2. **升版脚本误改文件名**：交接文件 §8 那段全仓字符串替换，在 v1166 → v1167 时会把 `_v1166.js` 的引用改坏。请用 `bump_version.py`（只改 `?v=` 戳）。详见 INTEGRATION 第 1 步。
3. **registry 37 KB 要放在 head 里同步加载**（为了首帧不闪）。gzip 后 13 KB，解析 1–2 毫秒量级；如果嫌大，可以接入时让构建工具另外生成一个只含 `resolve/apply` 的精简版，数据仍来自同一份 registry。
4. **门禁算的是设计值**；真画面里组件如果写死颜色，门禁看不见。已有组件样张逐像素测试兜底，迁移老组件时还要配真画面扫描（INTEGRATION 第 3 步）。
5. **只能真机确认的**：旧安卓上 🪙/🫧/🪼 是否空框（真机上可直接调 `HansenIcons.emojiOk('🪙')`）；低端机上 IMAX/画廊发热；宝箱光环、翻面彩纸算不算“闪”要老师点头；无头 Chromium 不是微信 XWeb。
6. **春节日期表写到 2035 年**，快用完时测试会红提醒补。
7. 庆祝引擎的“结算页卡片”长什么样（升级卡、进化卡、成就一行）是界面工作，引擎只负责排队和交回数据，接入时按样稿 `result.html` 画。
